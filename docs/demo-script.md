# 95 秒演示

准备本地法务演示账号、一份 Acme-Service-Agreement.docx，以及已验证的审查结果。页面右上角必须展示实际模型模式。真实模式以 TACC 彩排耗时决定是否现场执行。

| 时间 | 操作 | 讲解 |
|---|---|---|
| 0–10 秒 | 打开工作台，查看公司归档，上传样例 | 法务通过网页或专用邮箱提交合同，记录按账号和公司归档。 |
| 10–30 秒 | 选择标准审查或续约 Skill，提交 | Agent 通读分块合同，检索八类条款并提取原文证据。 |
| 30–55 秒 | 展开工具事件，点自动续约引用 | 通知期跨越两段，初轮证据不足后补查相邻段，最终引用能定位。 |
| 55–70 秒 | 查看清单标签并下载报告 | 示例清单要求至少 30 个自然日，证据为 60 日。模板可重复使用，报告可编辑导出。 |
| 70–85 秒 | 展示邮件任务和对应结果 | 同一流程处理邮箱来件，结果回传已绑定发件人。 |
| 85–95 秒 | 切总账户，展示文件 | 总账户只看输入原件和最终报告，个人会话和草稿保持独立。 |

如使用本地演示模式，开场明确这是工作流演示。真实模型评测图表与演示规则结果分开展示。最终录屏需由已连通的实际运行路径录制。
